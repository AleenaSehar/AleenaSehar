**[Retell Replica](https://github.com/AleenaSehar/Retell-replica)** — conversations modeled as a graph of nodes with LLM-evaluated transitions; the LLM acts as a constrained JSON routing engine, function nodes hit real APIs mid-conversation, and flows export to Retell AI's own schema.

**[Lantern](https://github.com/AleenaSehar/lantern-rag)** — RAG document Q&A where every answer exposes its exact source chunks. Evaluated retrieval, strict grounded generation, and lockfile-driven CI.

**[LeadFlow](https://github.com/AleenaSehar/Lead-generation)** — full lead-gen front office loop: capture, score, pipeline, and automated follow-up sequences, with real Supabase auth and a Postgres/Prisma data layer.

**[Skywatch](https://github.com/AleenaSehar/SkyWatch)** — NASA data dashboard (APOD, NEO, Mars rover) with independent failure handling per data source, not just a happy-path demo.
