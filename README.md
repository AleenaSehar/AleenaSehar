## Featured Projects

### 🔊 [Retell Replica](https://github.com/AleenaSehar/Retell-replica)
A from-scratch clone of Retell AI's conversational agent platform — not a prompt wrapper, an actual agent runtime. Conversations are modeled as a graph of nodes connected by **LLM-evaluated transitions**: the LLM acts as a constrained routing engine (JSON-only output, temperature 0) picking the next node, function nodes execute real HTTP calls mid-conversation and feed responses back into flow variables, and completed flows export to Retell AI's official schema so they run on the real platform.

`React Flow Builder` `LLM Routing` `Function Calling` `OpenAI` `Groq`

### 📄 [Lantern](https://github.com/AleenaSehar/lantern-rag)
A retrieval-augmented generation document Q&A app built to demonstrate a full, explainable AI engineering workflow — not just "embed and retrieve." Every answer exposes the exact source chunks used to generate it. Includes evaluated retrieval, strict grounded generation, interactive citations, frontend behavior tests, and lockfile-driven CI.
